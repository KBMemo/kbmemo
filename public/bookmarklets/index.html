kbmemo Web クリップ

Web ページの選択範囲を、出典 URL・ページタイトル付きで kbmemo エディタへ貼り付けやすい形式でコピーします。

次のリンクをブックマークバーへドラッグしてください。

kbmemo にコピー

使い方

  1. 引用したい Web ページでテキストを選択
  2. ブックマークバーの「kbmemo にコピー」をクリック
  3. kbmemo のメモエディタ（ソース編集または WYSIWYG ソース）で Ctrl+V

コピーされる内容

  • text/html … 選択範囲 + 出典メタデータ（URL・タイトル）
  • text/plain … プレーンテキスト

HTML 先頭の <!--kbmemo:{"url":"...","title":"..."}--> からページタイトルを読み取り、 末尾に link:URL[出典: タイトル] を自動追加します（出典ダイアログは表示されません）。

要件

  • Google Chrome 等、Clipboard API に対応したブラウザ
  • HTTPS ページ（localhost も可）

ソース

kbmemo_clip.js（読みやすい版）

kbmemo_clip.bookmarklet.js（ブックマーク用 1 行版）
