kbmemo Web クリップ

Web ページの選択範囲を kbmemo へ取り込みます。クリップボード経由と API 直保存の 2 方式があります。

API 直保存（おすすめ）

選択範囲を home/u-<id>/clippings に直接保存します。プロフィールで発行したクリップ API トークンが必要です。GitHub など connect-src が厳しいサイトでは、kbmemo の relay ページをポップアップで開いて保存します（ポップアップを許可してください）。

末尾の / は不要です。

プロフィール で発行した kbmemo_... をそのまま貼り付けてください（ページ URL や /bookmarklets/index.html ではありません）。

次のリンクをブックマークバーへドラッグしてください。

kbmemo に保存

使い方

  1. 引用したい Web ページでテキストを選択
  2. ブックマークバーの「kbmemo に保存」をクリック
  3. 保存完了後、必要ならメモを新しいタブで開く

クリップボード経由

kbmemo エディタで Ctrl+V して貼り付ける方式です。API トークンは不要です。

次のリンクをブックマークバーへドラッグしてください。

kbmemo にコピー

使い方

  1. 引用したい Web ページでテキストを選択
  2. ブックマークバーの「kbmemo にコピー」をクリック
  3. kbmemo のメモエディタ（ソース編集または WYSIWYG ソース）で Ctrl+V

送信される内容

  • html … 選択範囲 + 出典メタデータ（URL・タイトル）
  • plain … プレーンテキスト（HTML 変換のフォールバック）
  • url / title … ページ URL とタイトル

HTML 先頭の <!--kbmemo:{"url":"...","title":"..."}--> からメタデータを読み取り、 サーバー側で AsciiDoc に変換して link:URL[出典: タイトル] を末尾に追加します。

要件

  • Google Chrome 等、fetch に対応したブラウザ
  • HTTPS ページ（API 直保存は HTTP ページからでも kbmemo へ POST 可能）
  • API 直保存: kbmemo 側で CORS を許可済み（Access-Control-Allow-Origin: *）
  • HTTPS の Web ページから kbmemo へ POST する場合、kbmemo も HTTPS である必要があります（http://localhost へは Mixed Content でブロックされます）

ソース

  • kbmemo_clip_api.js（API 直 POST・読みやすい版）
  • kbmemo_clip_api.bookmarklet.js（API 直 POST・1 行版）
  • kbmemo_clip.js（クリップボード・読みやすい版）
  • kbmemo_clip.bookmarklet.js（クリップボード・1 行版）
