= 如意（Nyoy）MCP 連携

徒然 Workspace から如意 MCP を使うための要約。
**構成の正本**は如意リポジトリ link:https://gitea.artif.org/Artif.org/nyoy/blob/main/docs/architecture/nyoy-mcp.adoc[`docs/architecture/nyoy-mcp.adoc`]（エコシステム全体の責務分界・フェーズ見直し）。

== セットアップ

1. `cp .cursor/mcp.json.example .cursor/mcp.json`
2. `YOUR_MCP_API_TOKEN` を本番 `MCP_API_TOKEN`（nyoy `.env.production` と同じ値）に置き換える
3. Cursor で MCP サーバー `nyoy` を有効化

`.cursor/mcp.json` は git 管理外（トークン含むため）。

[source,json]
----
{
  "mcpServers": {
    "nyoy": {
      "url": "https://nyoy.kbmemo.net/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_API_TOKEN",
        "Accept": "application/json, text/event-stream"
      }
    }
  }
}
----

== 何を Nyoy MCP に任せるか

徒然 **in-app** `Chat::Agent` では pgroonga/pgvector RAG（`rag_search`）を継続する。
次は **徒然に実装せず** Nyoy MCP を使う（link:../../localai/nyoy/docs/architecture/nyoy-mcp.adoc[§6 フェーズ見直し]）。

* Web / URL: `web_search`, `fetch_url`, `search_fetched_page`
* 徒然 API 経由のメモ操作: `search_memos`, `get_memo`, `create_memo`, `update_memo`
* export ベース意味検索: `recall_memos`（如意側取込 RAG）
* 画像: `analyze_image`, `generate_image`, `refine_image`, `list_prompt_styles`
* 葛籠: `list_albums`, `get_media`

運用詳細: 如意 `docs/mcp-server.md`

== in-app Agent（Phase 9）

`/agent_chat` は `Chat::NyoyMcpClient` で同一 MCP ツールを HTTP 呼び出しする。
設定は `config/credentials/nyoy_mcp.example.yml` 参照（`NYOY_MCP_URL` / `NYOY_MCP_API_TOKEN` でも可）。

== stdio（ローカル開発）

如意を clone している場合:

[source,json]
----
{
  "mcpServers": {
    "nyoy": {
      "command": "/path/to/nyoy/bin/mcp-stdio",
      "env": {
        "MCP_API_TOKEN": "YOUR_MCP_API_TOKEN",
        "RAILS_ENV": "development"
      }
    }
  }
}
----
