= メモディレクトリの階層設計（Kbmemo）

このドキュメントは、Git 作業ツリー上のメモファイル配置と `memo_directories` テーブルの対応方針をまとめたものです。

== 目的

* **気軽にメモ** — 作成時に保存先フォルダを選ばない。`created_at`（Asia/Tokyo）の日付で自動配置する。
* **公開範囲はメモ単位** — `visibility` / `memo_group_id` で制御。ディレクトリは整理用のみ。
* Linux の ``/home`` に近いイメージで、**ユーザーごとの作業領域**を用意する。
* **共有（share）** は連携・同期用（Google Calendar、docs sync 等）。通常メモは `home` のみ。

== ルート直下のバケット

アプリのルート（`full_path` が空文字の `MemoDirectory`）の直下に、次の4つをシステムとして用意する。

[cols="1,3"]
|===
|バケット |役割

|`home`
|個人用。`home/u-{account_id}/YYYY-MM-DD` にメモを自動保存する。

|`share`
|連携用（`calendar`、`dev-docs` 等）。通常の手動メモ配置には使わない。

|`public`
|将来の整理用。ポリシー互換のため `public/u-{id}` ルートは維持。通常メモは `home` に統一。

|`system`
|アプリ共通の開発 doc・ヘルプ用。直下に `system/docs` と `system/help` を固定配置。
|===

`home` / `share` / `public` / `system` および ``home/u-{id}`` / ``share/u-{id}`` / ``public/u-{id}`` の行は **削除不可**（システム領域）とする。`system/docs` / `system/help` も構造変更不可。

== 日付ディレクトリ `home/u-{id}/YYYY-MM-DD`

* 新規メモは `MemoDirectory::UserSpace.date_directory` で `home/u-{account_id}/{created_at の日付}` を確保して割り当てる。
* 日付は **Asia/Tokyo** 固定（`MemoDirectory::UserSpace::DEFAULT_TIME_ZONE`）。基準は `memo.created_at`。
* 作成後の **手動移動は不可**（`memo_directory_immutable_after_create`）。例外: `docs_sync` 管理メモは同期処理がパスを更新できる。
* 日付ディレクトリ行は **削除・構造変更不可**（`date_directory?`）。

== 例外パス（日付自動配置の対象外）

[cols="2,3"]
|===
|パス例 |理由

|`system/docs` / `system/help`
|開発 doc・ヘルプ

|`share/u-{id}/dev-docs/...`
|`properties.docs_sync` 管理（KbmemoDocs sync）

|`home/u-{id}/clippings`
|Clip API（`ClipCreator`）。作成メモには `web-clip` タグを自動付与する。詳細は link:web-clipping.adoc[Web クリップ] を参照。

|`share/u-{id}/calendar`
|Google Calendar 同期
|===

== ユーザー識別子 `u-{account_id}`

* パスにメールアドレスやニックネームを使わず、**数値 ID ベースの不変セグメント** `u-42` のようにする。
* 表示名は `label`（例: メールの省略表示）で補う。

== 論理パス `full_path`

* `memo_directories` は `parent_id` でツリーを表し、**正規化された論理パス**を `full_path` に保持する（例: `home/u-42/2025-07-05`）。
* Git 上の相対パスは ``{full_path}/{slug}.adoc``（ルート直下メモのみファイル名のみ）とする。
* `full_path` は **一意**（グローバルユニーク）とし、`path_segment` の一意性は **同一親の子どうし**に限定する。

== アカウント作成時

* `Account` 作成後に `MemoDirectory::UserSpace.ensure_for_account!` を実行し、
  `home/u-{id}` / `share/u-{id}` / `public/u-{id}` の3行を **存在しなければ作成**する（冪等）。

== 既存データの移行

* `bin/rails kbmemo:memos:relocate_by_created_at_preview` — dry-run
* `bin/rails kbmemo:memos:relocate_by_created_at` — 適用（`GIT_RELOCATE=0` で DB のみ）
* 対象外メモを除き `created_at` の日付ディレクトリへ移動し、空になった旧ユーザー作成フォルダを削除する。

== 一覧・サイドバー

* ディレクトリタブは **日付フォルダツリー**で絞り込み。タグ・検索・履歴タブは従来どおり。
* ユーザーによるフォルダ作成・メモの DnD 移動・保存先ピッカーは **廃止**。
* `admin` アカウントは全ディレクトリを参照できる（`MemoDirectoryPolicy::Scope`）。
