= Modern Web Guidance ベースの Web 実装監査メモ
:toc:

このメモは、2026-06-11 時点の `kbmemo_site` を、Chrome の Modern Web Guidance を軸に
HTML / CSS / JavaScript / accessibility / performance / security の観点で見直し、
**実装修正の優先順位**を整理したものです。

== 参照

* Chrome for Developers, "Get started with Modern Web Guidance"
  https://developer.chrome.com/docs/modern-web-guidance/get-started
* Chrome for Developers, "Explore Modern Web Guidance skills"
  https://developer.chrome.com/docs/modern-web-guidance/explore-skills
* MDN, "HTML: A good basis for accessibility"
  https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/HTML

Modern Web Guidance は、semantic HTML、native interactive APIs、focus management、resource prioritization、
XSS/CSP/cookies などを中心に、モダンな Web 実装へ寄せるための指針群として整理されている。
本監査もその分類に合わせる。

== 実施ログ

* CSP は `config/initializers/content_security_policy.rb` で report-only として有効化。既存ページの違反収集を前提にし、enforcement は次段階に残す。

* `memo_ai_panel_controller.js` の error 表示を `innerHTML` から `textContent` / `createElement` ベースへ変更。
* `application.html.slim` / `diagram_viewer.html.slim` / `svg_editor.html.slim` に `lang="ja"` を付与。
* `application.html.slim` に skip link と `main#main-content` を追加。

* SVG editor entry から `svgedit` 本体と CSS の static import を外し、`memo_svg_editor_controller.js` 接続時の dynamic import に変更。`svg_editor` entry は約 2.19 MB から約 2.12 kB まで縮小し、SVGEdit 本体は `Editor` async chunk に分離した。
* editor / preview 系 import を package root から必要 module の direct import へ寄せ、`@kbmemo/adoc-kbmemo` の不要 export 巻き込みを削減した。`adoc-kbmemo` async chunk は約 1.10 MB から約 344.96 kB まで縮小した。

* `scripts/report-vite-bundles.mjs` に `--focus` filter を追加し、`npm run report:editor-bundles` で CodeMirror / Asciidoctor / editor 系 async chunk だけを測定できるようにした。
* release 前の Lighthouse / CWV / bundle size 確認手順を `docs/architecture/web-performance-checklist.adoc` に追加した。
* Rails model form の validation error 表示に `aria-invalid` / `aria-describedby` を付与する共通 helper を追加し、memo / memo directory / board / notebook / tag / profile の主要 field に適用した。
* `render_diagram` endpoint の成功レスポンスに `X-Kbmemo-Svg-Sanitized: MemoSvgSanitizer` / `X-Content-Type-Options: nosniff` / `Cache-Control: no-store` と `sanitized: true` を付与し、フロント側はこの契約を満たす SVG だけを挿入するようにした。
* `memo_ai_panel_controller.js` の message rendering も `innerHTML` から DOM API ベースへ変更し、AI 応答・ユーザー入力を常に text node として挿入するようにした。
* `memo_search_picker_controller.js` / `board_add_memo_controller.js` の検索結果描画を `innerHTML` 文字列組み立てから `createElement` / `textContent` / `dataset` ベースへ変更した。
* `tsuzura_picker_controller.js` の album list / photo list / error・empty 表示を `innerHTML` 文字列組み立てから `createElement` / `textContent` / `dataset` ベースへ変更した。
* `utility-compat.css` の重複 utility / 空 rule を削除し、`npm run check:utility-compat` で shrink-only baseline（有効行数・rule 数・重複 selector）を確認できるようにした。
* `application.html.slim` / `diagram_viewer.html.slim` の `html[data-kb-theme]` / `data-kb-theme-base` / `data-kb-skin` と `meta[name="color-scheme"]` を account theme preference から server-rendered にし、inline script なしで初期描画時のテーマちらつきを抑える構成へ変更した。
* `code_block_tools_controller.js` の copy / check icon 描画を固定 SVG 文字列の `innerHTML` から `createElementNS` / `replaceChildren` ベースへ変更した。
* `config.action_dispatch.default_headers` に `X-Content-Type-Options: nosniff` / `Referrer-Policy: strict-origin-when-cross-origin` / `Permissions-Policy: camera=(), geolocation=(), microphone=()` を明示し、低リスクな browser security companion policy を固定した。
* CSP report-only の収集導線として `POST /csp_reports` を追加し、`report-uri /csp_reports` と `Reporting-Endpoints: csp="/csp_reports"` を設定した。受信 payload は認証なしで `204` を返し、ログは query / fragment を落とした最小フィールドに限定する。
* `scripts/report-vite-bundles.mjs` に `--kind` filter を追加し、`npm run check:bundle-budget` で `entry` bundle を 520 kB 以内に固定する CI 向け budget check を追加した。
* メモ編集フォームとディレクトリサイドバーの `<details>` ヒントは、アイコンだけの `summary` に `aria-label` / `aria-describedby` を付け、説明本文へ接続した。
* `@kbmemo/adoc-wysiwyg` の web paste / image paste / search-replace dialog の固定 HTML template と、空段落 placeholder の固定 HTML を `createElement` / `textContent` / `append` ベースへ変更した。
* メモ一覧 / AI パネルのサイドバー resizer に `aria-valuetext` を追加し、keyboard resize だけでなく drag resize 中も `aria-valuenow` / `aria-valuetext` を同期するようにした。
* テーマスタジオのカスタムスキン入力、ボードへの新規カード追加 / 既存メモ検索、AI パネル prompt textarea に `label.sr-only` と必要な `autocomplete` を追加し、placeholder を accessible name として使わない構成へ寄せた。
* メモサイドバー検索とメモ表示画面のタグ追加入力に `label.sr-only` を追加し、placeholder / `aria-label` 依存を減らした。
* メモ本文エディタの編集モード切替を `role="tab"` + `aria-selected` + `tabpanel` 接続へ揃え、Arrow / Home / End で roving tabindex 操作できるようにした。
* ダイアグラム新規作成フォームの補助文を `aria-describedby` で入力欄へ接続し、編集 / ソース / SVG ビューアに preview live region、CodeMirror の説明接続、ズームボタンの `aria-label` を追加した。
* プロフィールのトークン発行後スクロール用 inline script を削除し、`scroll-into-view` Stimulus controller で対象 section へスクロール / focus する構成に変更した。
* メモ一覧のドラッグ専用ハンドルから `role="button"` / `tabindex` を外し、ポインタ専用の補助操作として accessibility tree から除外した。キーボード操作ではメモ編集フォームの保存先フォルダ欄を使う説明をヒントに追加した。
* `:user-invalid` と `aria-invalid` を同期する軽量 bridge を追加し、browser native validation が表示されるタイミングで assistive technology へも invalid state を伝えるようにした。server validation 由来の `aria-invalid` は bridge 側で解除しない。
* `expandable-hint` の icon-only toggle は `title` に頼らず `aria-label` を持つようにし、開閉状態に合わせて `aria-expanded` / `aria-label` / `title` を同期する。
* Gravatar の `img` に表示サイズと同じ `width` / `height` 属性を追加し、CSS 適用前でも aspect ratio を予約して CLS を抑える。
* メモ詳細 / 編集フォーム上部の Gravatar は above-the-fold なので `loading="eager"` にし、非 LCP の小画像として `fetchpriority="low"` を付ける。サイドバー一覧の avatar は offscreen 行が多いため lazy loading を維持する。
* メモサイドバー検索とボードの既存メモ検索を `<search>` 要素で囲み、検索 UI を native landmark として表現する。
* メモ本文 HTML の画像後処理で、既存の `loading` 指定を尊重しつつ `decoding="async"` 未指定の画像へ補完するようにした。

== 現状の良い点

* semantic な `button` / `details` / `dialog` をすでに多用している。
* flash 通知に `aria-live="polite"` が入っている。
* avatar と本文画像系には `loading` / `decoding="async"` が使われている。avatar は `width` / `height` 属性も持ち、above-the-fold の単体 avatar は eager + low priority にしている。
* production では `force_ssl = true`、host 制限、cookie store を使っている。
* Tailwind 依存を外し、テーマ設計を `themes.css` と Open Props に寄せている。

=== 4. Performance

* Vite build は成功するが、CodeMirror と SVGEdit 本体の async chunk size warning は継続している。
* Gravatar は `width` / `height` 属性で intrinsic size を明示し、layout shift を避ける。メモ詳細 / 編集フォーム上部の単体 avatar は eager loading、サイドバー一覧 avatar は lazy loading で扱う。

== 補足

Modern Web Guidance は、最新機能を無条件に採用すること自体を目的にしていない。
`Baseline` と fallback を前提に、**native で済むものは native に寄せ、JS は必要なところだけに限定する**
という方向が中心にある。`kbmemo_site` では、すでに `dialog` / `details` / semantic button が入っているため、
全面作り直しではなく、**CSP・focus management・bundle 分割**の3本を先に締めるのが最も効果的である。
