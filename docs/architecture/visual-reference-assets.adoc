= Visual Reference Assets

This directory records non-runtime visual reference material for KBMemo and related projects.
These files are intentionally kept outside `app/assets/images` so they are not treated as application UI assets until a concrete implementation chooses to use or adapt them.

== Usage Policy

* Treat these files as design references, not production assets.
* When a reference is adopted into the product UI, copy or derive the final optimized asset into the appropriate runtime asset directory and document the use at that time.
* Keep original reference filenames stable so design notes and issue links remain valid.
