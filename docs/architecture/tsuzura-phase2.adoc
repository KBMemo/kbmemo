= Tsuzura Phase 2 — Web UI とメモ編集ピッカー

link:media-platform.adoc[media-platform.adoc] の **Phase 2**。**2026-06 実装完了**（Phase 1 は同月完了）。

== 実装サマリ

[cols="2,3"]
|===
|領域 |内容

|`kbmemo-media`
|最小 Web UI（アルバム一覧・詳細・作成・複数 upload）。`GET /internal/albums?owner_account_id=`。`rack-cors`（`TSUZURA_CORS_ORIGINS`）。`config.api_only = false`、Rodauth 共有 Cookie

|`kbmemo_site`
|メモ編集の「Tsuzura」ピッカー（`tsuzura-picker` Stimulus）。`GET /internal/tsuzura/albums`・`GET /internal/tsuzura/albums/:id`（Tsuzura プロキシ + 所有者チェック）。`POST /internal/tsuzura/sign_urls`（JSON + CSRF）。ソース／ライブプレビュー／WYSIWYG で `substituteTsuzuraForPreview`

|===

== 前提（Phase 1）

* `kbmemo-media`: `tsuzura_*` テーブル・Active Storage・`POST /v1/media/batch`・`bin/tsuzura import`
* `kbmemo_site`: `album::` / `image::media:` 表示・`POST /internal/tsuzura/sign_urls`・CLI トークン（プロフィール）
* 環境変数: `TSUZURA_PUBLIC_URL` / `TSUZURA_BASE_URL` = `https://media.kbmemo.net`（本番）
* nginx `media.kbmemo.net`: `client_max_body_size` **512M 以上** — link:../deployment/production.adoc#tsuzura-nginx[production.adoc]
* デプロイ: `kbmemo_site` → `bin/deploy`、`kbmemo-media` → `bin/deploy`（**Tsuzura テーブルは media 側 `db:migrate`**）

== ユーザー向け機能

* **media.kbmemo.net** — ログイン済み（`_kbmemo_session` 共有）でアルバム一覧・写真 upload
* **メモ編集** — ツールバー「Tsuzura」からアルバム一括挿入（`album::ULID[]`）または画像複数選択（`image::media:ULID[]`）
* **プレビュー** — 本文は ULID マクロのまま。表示・編集プレビュー・WYSIWYG で署名 URL に展開（本文に署名 URL は保存しない）

== API（Phase 2 追加分）

=== kbmemo-media

[cols="1,2,2"]
|===
|Method |Path |用途

|GET
|`/internal/albums?owner_account_id=`
|KBMemo サーバー向けアルバム一覧（`X-Kbmemo-Internal-Secret`）

|GET
|`/internal/albums/:id`
|Phase 1 から（アルバム中身）

|===

Web（Cookie 認証）: `/` 一覧、`/albums/:id` 詳細・upload、`/albums/new` 作成。

=== kbmemo_site（ログイン必須・同一オリジン）

[cols="1,2,2"]
|===
|Method |Path |用途

|GET
|`/internal/tsuzura/albums`
|ログインユーザーのアルバム一覧 JSON

|GET
|`/internal/tsuzura/albums/:id`
|アルバム詳細（所有者のみ）

|POST
|`/internal/tsuzura/sign_urls`
|`memo_id` + `media_ids[]` / `album_ids[]` → 署名 URL（`Content-Type: application/json` + CSRF）

|===

== 環境変数

=== KBMemo（`.env.production`）

[source,bash]
----
TSUZURA_BASE_URL=https://media.kbmemo.net
TSUZURA_PUBLIC_URL=https://media.kbmemo.net
KBMEMO_TSUZURA_INTERNAL_SECRET=…  # credentials と同一
----

=== kbmemo-media（`.env.production`）

[source,bash]
----
KBMEMO_TSUZURA_INTERNAL_SECRET=…  # KBMemo と同一
KBMEMO_LOGIN_URL=https://kbmemo.net/login
KBMEMO_HOME_URL=https://kbmemo.net
# 任意（既定: kbmemo.net + localhost:3000）
TSUZURA_CORS_ORIGINS=https://kbmemo.net,https://www.kbmemo.net,http://localhost:3000
----

== 受け入れ条件（完了）

. `https://kbmemo.net` ログイン後、`https://media.kbmemo.net` でアルバム作成・upload ができる
. メモ編集ピッカーで `album::` / `image::media:` を挿入し、show・ライブプレビュー・WYSIWYG で HTTPS 画像が表示される
. 未共有メモでは他ユーザーに `sign_urls` が通らない（Phase 1 の `MemoPolicy#show?` 維持）
. 本番で Mixed Content・413・CSRF 422 が再発しない設定（link:../deployment/production.adoc[production.adoc]）

== 技術メモ

=== 認証

* ブラウザ Web UI: **Rodauth 共有 Cookie**（`_kbmemo_session`）
* CLI: `tsuzura_api_token`（Phase 1 同型）
* KBMemo ↔ media サーバー間: `X-Kbmemo-Internal-Secret`
* ピッカー・ドラフト保存: `POST` に `X-CSRF-Token` + JSON `authenticity_token`（`fetch` ラッパーで meta 同期）

=== 本文マクロ

[source,asciidoc]
----
album::01JHABCD1234567890ABCDEF[]
image::media:01JHBCDF1234567890ABCDEF[width=720]
----

* サーバー show: `MemoTsuzuraMacro`
* クライアント: `packages/adoc-kbmemo/src/tsuzura_substitute.js`、`packages/adoc-wysiwyg/wysiwyg.js`（URL 取得後にユニット再描画）
